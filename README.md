# 🐔 El Pollo Loco

A small 2D browser game built with **JavaScript, HTML and Canvas**.  
The player controls Pepe and must defeat chickens, collect coins and bottles, and defeat the end boss.

## 🎮 Live Demo

Play the game here:

https://mya63.github.io/El-Pollo-Loco/

## 🕹️ Controls

| Key | Action |
|----|----|
| ← / → | Move left / right |
| Space | Jump |
| D | Throw bottle |

## 🧩 Game Features

- 2D side-scrolling game using **HTML5 Canvas**
- Enemy system with **normal chickens and small chickens**
- **Endboss fight**
- **Bottle throwing mechanic**
- **Coin collection system**
- Health, coin and bottle **status bars**
- Game **win and lose screens**
- Sound effects and background music
- Mobile control buttons

## ⚙️ Technologies

- JavaScript (ES6)
- HTML5
- CSS3
- Canvas API

## 📂 Project Structure

```

js/
models/
levels/
audio/
img/

```

Important components:

- `world.class.js` – main game logic
- `character.class.js` – player behavior
- `movable-object.class.js` – base physics class
- `status-bar.class.js` – UI status bars
- `game.core.js` – game bootstrap and UI handling
